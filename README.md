# Introduction App

### App Description

This iOS app allows users to create a personalized introduction. Users can enter their first name, last name, and school name, select their academic year, choose the number of pets they have, and indicate whether they want more pets. When the "Introduce Self" button is tapped, the app displays the user's introduction in an alert box.
